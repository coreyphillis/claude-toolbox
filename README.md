# claude-toolbox

Skills and templates used across repos.

This repo is a [Claude Code plugin marketplace](https://docs.claude.com/en/docs/claude-code/plugins)
named `corey-tools`.

## Install

```
/plugin marketplace add coreyphillis/claude-toolbox
/plugin install slide-figure@corey-tools
```

## Contents

- **plugins/slide-figure** — generate clean, presentation-ready figures and
  diagrams for slides.
- **templates/** — reusable project scaffolds and boilerplate.
